Thêm đoạn này vào mảng "headers" trong firebase.json (nằm NGOÀI thư mục public, ở /sdcard/<thư mục deploy>/firebase.json).
Các file js/posgieo/*.vN.js có số phiên bản trong tên, sửa nội dung = đổi tên file → cache lâu an toàn.

{
  "source": "/js/posgieo/**",
  "headers": [
    { "key": "Cache-Control", "value": "public, max-age=31536000, immutable" }
  ]
}
